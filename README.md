## AlphaTab Web Viewer

A browser-based Guitar Pro viewer is available in `web/`, using the stable `@coderline/alphatab` 1.8.4 package.

Run it with:

```bash
cd web
npm install
npm run dev
```

It supports Guitar Pro files, standard notation + TAB, playback controls, and the AlphaTab playback cursor.
